Политика конфиденциальности

Приложение TruckLog

Настоящая Политика конфиденциальности описывает, как приложение «TruckLog» (далее — «Приложение») обрабатывает данные Пользователя.

1. Общие положения

1.1. Мы уважаем конфиденциальность Пользователей и стремимся к максимальной прозрачности.

1.2. Использование Приложения означает полное и безоговорочное согласие Пользователя с настоящей Политикой.

2. Сбор и хранение данных

2.1. Отсутствие серверов. Разработчик не имеет серверов для сбора персональных данных. Мы не собираем ваши ФИО, номера телефонов, email, геолокацию или данные банковских карт.

2.2. Локальное хранение. Вся вводимая статистика (баланс, рейсы, история, настройки) сохраняется исключительно на устройстве Пользователя в локальной базе данных.

2.3. Доступ. Разработчик не имеет удаленного доступа к вашей статистике. При удалении Приложения все данные стираются навсегда (если Пользователь не сделал резервную копию).

3. Использование разрешений (Permissions)

Для корректной работы Приложение запрашивает следующие разрешения:

  • Отображение поверх других приложений: Используется исключительно для отображения плавающей панели, чтобы Пользователь мог вносить данные, не сворачивая игру.
  • Уведомления: Используется для системных оповещений о завершении рейса или смены.
  • Вибрация: Используется для тактильного отклика при нажатии кнопок.

4. Сторонние сервисы

4.1. Приложение не содержит сторонних программных библиотек, трекеров или рекламных сетей.

4.2. Приложение не собирает аналитику использования.

5. Права Пользователя

5.1. Пользователь вправе в любой момент удалить все свои данные, воспользовавшись кнопкой «Сброс настроек» внутри Приложения или удалив само Приложение с устройства.

5.2. Пользователь вправе не предоставлять разрешения (п. 3), однако в этом случае работа определенных функций (например, плавающей панели) будет невозможна.
