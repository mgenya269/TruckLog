MATRESHKA TRUCK HELPER — проект Android-приложения

Что умеет версия 1.0:
- старт/завершение ручного таймера рейса;
- начисляет 15 000 ₽ за завершённый рейс;
- считает число рейсов, средний заработок в час и прогресс к 5 000 000 ₽;
- сохраняет статистику на устройстве;
- позволяет задать текущий баланс и сбросить статистику.

Важно: приложение не управляет игрой, не нажимает кнопки и не выполняет рейсы автоматически.
Время рейса учитывается по часам телефона. Если закрыть приложение во время рейса, отсчёт продолжится после открытия.

СБОРКА APK БЕЗ КОМПЬЮТЕРА:
1. На телефоне открой github.com и войди/создай аккаунт.
2. Создай новый репозиторий (New repository), например matreshka-truck-helper.
3. Распакуй ZIP и загрузи ВСЕ файлы и папки проекта в корень репозитория через Add file -> Upload files.
4. После загрузки открой вкладку Actions. Если GitHub попросит разрешить workflow, нажми разрешение.
5. Открой workflow "Build Android APK" и нажми Run workflow (или дождись автоматического запуска после загрузки файлов).
6. Когда сборка закончится зелёной галочкой, открой запуск и скачай Artifact "Matreshka-Truck-Helper-APK".
7. Распакуй скачанный архив и установи app-debug.apk. Android может попросить разрешить установку из этого источника.

Если GitHub на телефоне неудобен, можно использовать браузер в режиме "Версия для ПК".
Для сборки требуется интернет и аккаунт GitHub. APK на данный момент не собран и не подписан для публикации в Google Play; это debug APK для личной установки.
